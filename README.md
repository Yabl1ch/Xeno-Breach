# XENO-BREACH // 3D Arena Shooter

> Интенсивный 3D-шутер от первого лица на **Three.js** с детерминированной физикой движения (`120 Гц`), честными **Air-Strafe** и **BunnyHop (BHop)**, полимерной перчаткой способностей в духе *Atomic Heart*, крафтом укреплений как в *Fortnite / Rust* и 3-ярусной орбитальной ареной с боевыми ДОТами.

## Ключевые особенности

- **Движение на уровне Quake / Source (`120 Гц`)**:
  - Настоящий **Air-Strafe** с ускорением на дугах в воздухе и **BHop** (поддерживаются как точные тайминги прыжка, так и зажатый `Space`), подкат и присед за укрытия (`Left Ctrl`), тактический рывок (`Shift`), грави-трамплины и проходимые 3D-рампы.
- **3-ярусная орбитальная арена и шлюзы**:
  - Три игровых уровня (`0 м`, `4.0 м`, Skybridge `8.0 м`), 4 укреплённых боевых ДОТа с амбразурами, тактические коридоры укрытий, широкие открытые трассы для БХопа и навигация врагов по Flow-Field с 4 северных шлюзов.
  - Точный Ray-AABB расчёт обзора и CCD-физика снарядов исключают прохождение или прострел сквозь стены.
- **Арсенал из 12 пушек в 6 активных слотах (`1–6`)**:
  - Плазмомёт MK-IV, Энерго-Дробовик X7, Пулемёт «Вулкан-200», **«ГЕЛИОС-П»** (бесконечно заряжаемая сфера полимера с масштабируемой ударной волной против орд и боссов), «Супернова», ПП «Шершень-VX», Огнемёт «Инферно», Рельсотрон «Гиперион», Тесла-дуга «Зевс», Крио-миномёт «Метель», ракетница «Гидра-3» и крафтовый 6-ствольник **Гатлинг «Буря-M6»**.
  - 4 категории обвесов за монеты (`Ствол`, `Магазин`, `Оптика`, `Ядро`) с отображением 3D-модулей прямо на оружии.
- **Полимерная перчатка — 6 активных ячеек и 9 способностей**:
  - Радиальное колесо выбора (удерживать `Q` или `G`) и быстрые клавиши `Q / E / F / T / V / Y`.
  - Включает Энергощит «Эгида», Заморозку, Полимерный Огонь, **Замедление времени (`0.22x`)**, **Откидывание**, **Полимер-Турель «Страж-П»**, Стоп-время, Телекинез и ЭМИ-Сифон, а также 3 ветки прокачки каждой способности.
- **Постоянное строительство за монеты (`[C]`) и обвесы стен (`[U]`)**:
  - Постоянные укрепления с авторемонтом между волнами: Стены, Стены-бойницы, укрывной **Броне-ДОТ** с крышей и бойницей (садитесь за передний щит на `Ctrl` и отстреливайтесь), штурмовые Рампы и **Постоянный 6-ствольный Гатлинг «Вулкан»**.
  - 4 тактических обвеса на стены: Титановая броня МВК, Электро-шипы «Колючка», Полимер-щит надстройки и Навесной Мини-Гатлинг.
- **Лут, экономика и перерывы между волнами**:
  - Гарантированный дроп кристаллов и монет с автоматическим вакуум-сбором всех оставшихся на арене ресурсов в конце каждой волны.
  - 8 классов брони вплоть до Экзо-Апекса «Нео-Квант Ω» (при срыве щита автоматически разряжает весь остаток полимера ударной волной 360°).
  - Неограниченная передышка между раундами с запуском следующей волны выстрелом в золотой маяк.

## Управление

| Клавиша | Действие |
| :--- | :--- |
| `W A S D` | Движение и Air-Strafe в воздухе |
| `Space` | Прыжок и BunnyHop (BHop) |
| `Left Ctrl` | Присед за укрытием / Подкат на высокой скорости |
| `Shift` | Тактический рывок по направлению движения |
| `ЛКМ` / `ПКМ` | Стрельба (зажать на «Гелиос-П» и «Супернове») / Постройка в режиме стройки |
| `1 – 6` | 6 активных слотов оружия (в режиме стройки — выбор чертежа `1–6`) |
| `R` | Перезарядка (в режиме стройки — поворот объекта на `90°`) |
| `C` | Включить / выключить режим строительства (`Стены`, `Броне-ДОТ`, `Рампа`, `Гатлинг`) |
| `U` | Установить выбранный обвес на стену в прицеле |
| `Q` (удержать) / `G` | Радиальное колесо полимерной перчатки (6 секторов) |
| `Q E F T V Y` | Быстрое применение 6 активных ячеек перчатки (`Y` — Полимер-Турель) |
| `Z` / `X` | Бустер скорости / Полевая аптечка |
| `B` / `Tab` | Открыть 5-вкладочный Магазин и Верстак |
| `P` / `Esc` | Пауза / Выход из меню |

## Локальный запуск

Проект не требует сборки и работает прямо через любой статический HTTP-сервер (или локально из `index.html`):

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.
